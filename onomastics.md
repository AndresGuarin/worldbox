# My onomastics

**How to use:** in-game, go to a culture's **Onomastics Glyphs** tab, pick a category (Units / Families / Clans / Villages / Kingdoms), and use **Load template from clipboard** with the matching string below copied to your clipboard.


## Unit Names

```
4M5M2F3F|2:ae bae dae helae lae rhae;3:la mma na nyra nys;4:ae bae dae mae rhae;5:gon kar lon lor mon mond ron
```
**Examples:** Aemma, Aegon, Laena, Daemon, Maekar.

```
4M5M2F3F|2:ae bae dae helae jaeha lae rhae visen;3:la mma na nerys nyra nys ya;4:ae bae dae jacae jaehae lucae mae rhae vise;5:gar gon kar lon lor mon mond ron rys
```

**Examples:** Aemma, Visenya, Aenys, Lucaerys, Jacaeron.

## Family names
I use the ones for English present in [worldbox-onomastics](https://github.com/WeepingBoil/worldbox-onomastics/tree/main)

## Village Names

The names correspond to adjetive + noun such as Nightsong, Hightower, Sunstone, etc.

```
01|0:black craken dread golden harren high night old sander summer;1:fort garden grove hall heaven song stone stones tower waters
```

**Examples:** Blackwaters, Goldenhall, Oldgrove, Dreadfort.

## Clan Names

```
`0|0:baratheon belaerys blackfire celtigar dragonhorn goldenfire ironfire silverdragon targaryen velaryon`
```
**Examples:** Baratheon, Blackfire, Celtigar.

## Kingdom Names

```
0_1|0:ancient ashen eastern elder far franco high holy iron middle new north northern old royal sacred silver southern sovereign western;1:barony commonwealth demesne dominion duchy earldom land march palatinate principality protectorate realm shire vale valyria
```

**Examples:** Ancient Valyria, Eastern Barony.
